Purpose

The RFAL Library (RF Abstraction Layer) provides several functionalities required to perform RF/NFC communications.The RFAL encapsulates the different RF ICs (ST25R3911, ST25R3916, ST25R200, ST25R500, ST25R95 and future ST25R devices) into a common and easy to use interface.

The technologies currently supported by RFAL are:

  • NFC-A \ ISO14443A (T1T, T2T, T4TA)
  • NFC-B \ ISO14443B (T4TB)
  • NFC-F \ FeliCa (T3T)
  • NFC-V \ ISO15693 (T5T)
  • P2P \ ISO18092 (NFCIP1, Passive-Active P2P)
  • ST25TB (ISO14443-2 Type B with Proprietary Protocol)
  • PicoPass \ iClass
  • B' \ Calypso
  • CTS \ CTM

The protocols provided by RFAL are:

  • ISO-DEP (ISO14443-4)
  • NFC-DEP (ISO18092)
